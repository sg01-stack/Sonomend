`scene.glb` is the original SonoMend megaphone and six separate capsules. Runtime materials add stronger Fresnel edges and neutral studio highlights. A separate cube reflection of the megaphone is used only during reveal/interaction. Neither the original Blender project nor the GLB bytes were changed.

`pin-only.glb` is copied unchanged from the user's `SonoMend-map-reveal` output. SHA-256: `8F9D19BF490698728847736773E0E3DB61F434BED6DC5F42B2631D1EED20C726`.

The authored five-second pin animation drops/shrinks until 3.2 seconds and holds after contact. The application reveals the real Leaflet map with one circular clear area from 3.2 to 4.67 seconds. No synthetic map texture or rendered video is displayed. Reduced-motion preference skips the animation. Only live location or demo simulation updates the map center; the pin tip stays at the viewport center. No original asset files were overwritten.
