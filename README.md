# Sonomend

Live site: [sonomend.onrender.com](https://sonomend.onrender.com)

A mobile-first, on-device hackathon MVP: **Calibrate & Start → Navigate + earn points → End Trip → Trip Report**. Plain TypeScript, CSS, Vite, Web Audio, Geolocation, and IndexedDB. The core needs no backend, account, paid API, cloud inference, or remote fonts. A separate optional hosted sound check is disabled by default. Audio inference and app assets run locally; optional online navigation uses free public map services.Ever wondered why people honk tirelessly even when there's no clear point? Well i did too , and it came out to be a deeply rooted habit  , so to change it i built sonomend , a web app that catches proper and improper usage of horns to issue rewards or penalty to the users , this is the mvp while im looking to get it published as a gov approved app.
